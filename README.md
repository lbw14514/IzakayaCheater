# IzakayaCheater

东方夜雀食堂的存档修改器 能改金钱 开全地图 拉满好感 强开本体和 DLC1~DLC5 的 Boss 再战
支持游戏 4.4.0

慢慢打太累了 做修改器也不轻松

## 先说风险

本项目是第三方非官方工具 和游戏开发团队 发行方没有关系 也没被授权

仓库不含游戏本体资源 程序运行时也不改游戏本体文件 只读写你本机上的存档

改坏了 进度丢了 账号出问题 都由你自己承担

## 用之前

> **一定先备份存档**
> 修改器只做写入 不做回滚

1. 关掉 Steam 云同步 库 右键游戏 属性 通用 取消勾选保留在云 否则改完会被云同步还原回去
2. 只玩过本体的 先用开全地图 不然 DLC 地区根本去不了
3. 排队事件方案已经停用 按钮是灰的 光改存档触发不了 要游戏运行时调用它自己的调度器 等于改内存 没做
4. 用标记通关开 DLC 战时 进度没到的可能丢未完成进度 再强调一次 备份
5. 用管理员身份运行

## 跑起来要什么

- Windows 10 或 11
- WebView2 运行库 Win11 自带 Win10 装了新版 Edge 也有 没有就装一下 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)
- 打开就是界面 不用浏览器 关窗口即退出
- 不联网 本地服务只监听 127.0.0.1

## 能改什么

| 功能 | 做了什么 |
|---|---|
| 金钱 | 改 playerPartial.fund |
| 开全地图 | 本体 6 张加 DLC 11 张共 17 张全开 同时补写 DLC 激活项 |
| 满好感 | 所有角色等级拉到 5 经验 9999 满进度档 78 个 纯本体档 29 个 |
| 强开 Boss 战 | 本体加 DLC1~5 共 6 场 |

地图和好感都重复点没事 第二次一般返回 0 或结果不变

## 强开 Boss 战

选存档 选战斗 点方案

| 方案 | 状态 | 说明 |
|---|---|---|
| 排队事件 | 停用 | 只往存档写 scheduledEvents 触发不了 |
| 标记通关 | 可用 | 把该战标记为已完成 解锁游戏里的再战入口 要自己去对应地点点 |
| 邀请函 | 可用 | 给物品 2014~2019 加好感 走原版路线 只有 DLC2 有 |

## 常见问题

**启动后白屏**
装 WebView2 Runtime 装完重开

**改了没效果**
先确认关了 Steam 云同步 标记通关还要你自己去 NPC 那里点再战

**会坏档吗**
先备份 多数功能重复点没事 标记通关可能因进度未到丢未完成内容

**联网吗**
不联网 只读写本机存档
